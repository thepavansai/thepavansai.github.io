# G. Pavan Sai Sriram's Portfolio

Personal portfolio website built with React and Parcel.

## Run locally

```bash
npm install
npm start
```

## Build

```bash
npm run build
```

## GitHub Pages deployment

This repository is configured for root deployment on:

- https://thepavansai.github.io

Deploy command:

```bash
npm run deploy
```

The deploy script publishes the built `dist/` output to the `gh-pages` branch.
